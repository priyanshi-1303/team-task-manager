# Team Task Manager

A full stack Team Task Manager web app built using React, Node.js and MongoDB concepts.

## Features

- Authentication UI
- Role Based Access (Admin/Member)
- Project Management
- Task Creation & Assignment
- Dashboard Analytics
- Team Management
- Responsive UI

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Vercel Deployment
